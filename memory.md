Landing page institucional para **Xtreme-Park Mendoza**, parque de paintball en Mendoza, Argentina.

## Decisiones tomadas
- **Stack**: HTML5 semántico + CSS3 (custom properties, Grid/Flexbox) + JS vanilla (ES6+). Sin frameworks ni bundlers.
- **Idioma**: contenido en español (es-AR).
- **Diseño**: tema oscuro (`#0a0b0d`) con acento naranja (`#ff4d00`), tipografía `Bebas Neue` + `Barlow`.
- **Galería**: sin imágenes locales; tiles con gradientes CSS e iconos.

## Contexto del usuario
- El usuario prefiere respuestas e interfaces en español.
- El proyecto es una landing page de un negocio local (paintball en Mendoza).
